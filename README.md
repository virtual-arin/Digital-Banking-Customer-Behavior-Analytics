## 📈 Dataset 
* **Source:** [Bank Customer Segmentation](https://www.kaggle.com/datasets/shivamb/bank-customer-segmentation/data)

## 🛠️ Methodology
1. **Data Collection:** Obtain banking customer and transaction data from the selected dataset.
2. **Data Cleaning:** Handle missing values, duplicates, inconsistent records, and data type issues using Pandas.
3. **Data Preprocessing:** Transform and prepare data for analysis through feature engineering and formatting.
4. **Exploratory Data Analysis:** Analyze customer demographics, transactions, balances, and usage patterns.
5. **Data Visualization:** Create charts and dashboards using Matplotlib and Seaborn.

## 💻 Technologies Used
* **Language:** Python
* **Data Manipulation & Visualization:** Pandas, NumPy, Matplotlib, Seaborn
* **Version Control:** Git & Github
* **Environment:** Jupyter Notebook
