# Digital-Banking-Customer-Behavior-Analytics 

## Domain: Financial & Banking

# 🤔 Problem Statement
Digital banks generate large amounts of customer transaction and usage data. The goal of this project is to analyze customer behavior, digital banking adoption, spending patterns, account activity, and product usage to identify active and inactive customers, improve engagement, and discover opportunities for revenue growth.

## 🎯 Objective
To analyze customer banking behavior and transaction patterns, identify customer segments, measure engagement levels, and provide data-driven insights that support customer retention, targeted marketing, and business growth.

## 📈 Dataset 
* **Source:** [Bank Customer Segmentation](https://www.kaggle.com/datasets/shivamb/bank-customer-segmentation/data)

## 🛠️ Methodology
1. **Data Collection:** Obtain banking customer and transaction data from the selected dataset.
2. **Data Cleaning:** Handle missing values, duplicates, inconsistent records, and data type issues using Pandas.
3. **Data Preprocessing:** Transform and prepare data for analysis through feature engineering and formatting.
4. **Exploratory Data Analysis:** Analyze customer demographics, transactions, balances, and usage patterns.
5. **Customer Segmentation:** Group customers based on behavior, transaction activity, and account value.
6. **RFM Analysis:** Measure Recency, Frequency, and Monetary value of customers.
7. **Statistical Analysis:** Identify trends, correlations, and key business drivers.
8. **Data Visualization:** Create charts and dashboards using Matplotlib and Seaborn.
9. **Insight Generation:** Derive actionable business recommendations from findings.
10. **Reporting:** Present results through an analytics dashboard and project report.

## 💻 Technologies Used
* **Language:** Python
* **Data Manipulation & Visualization:** Pandas, NumPy, Matplotlib, Seaborn
* **Version Control:** Git & Github
* **Environment:** Jupyter Notebook
